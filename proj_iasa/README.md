Na linguagem de programação Python, uma interface é implementada da mesma forma que uma classe abstrata, sendo utilizada a biblioteca abc para a classe herdar a classe ABC. A diferença existente entre uma classe abstrata e uma interface é a não existência obrigatória de atributo, não sendo necessária a utilização de construtor por parte da interface. 
Para que seja evitado o uso estrutural de uma classe, a ação do agente inteligente foi 
implementada sob a forma de uma interface, evitando assim uma complexidade desorganizada.
